# Stable path P4: repaired bottom-pair theorem on \(s=6\)

Let

\[
B_\epsilon(m,s,x)
=H_q^L(2m+\epsilon,0)+H_q^L(2m+\epsilon,1),
\]

where

\[
q=m+s+2,\qquad L=2q-4+x.
\]

For every \(m\ge3\), \(x\ge0\), and
\(\epsilon\in\{0,1\}\),

\[
B_\epsilon(m,6,x)\ge0
\tag{1}
\]

and

\[
B_\epsilon(m+1,6,x)
\ge B_\epsilon(m,6,x).
\tag{2}
\]

This is the first support diagonal on which the old separate
\(H(j,0)\) lift fails.  Thus (1)--(2) give an exact repair at the
first obstruction.

## Polynomial architecture

Put \(m=3+M\).  The centered fixed-support windows at \(s=6\) have
at most 20 terms.  After writing the convolution coordinate as
\(u=m+v\), every residual rank in the four path-moment formulas is
a fixed integer.  Each path count or moment is therefore a
falling-factorial polynomial in \(M,x\).

The only parameter denominators arise from centered binomial ratios
and the adjacent central-binomial ratio used in (2).  Termwise
inspection of the support windows shows that

\[
D(m)=\prod_{i=1}^{11}(m+i)
\]

clears all of them.  The same termwise falling-factorial count gives
the coordinate degree bounds

\[
\deg_M\le28,\qquad \deg_x\le14
\tag{3}
\]

for each of

\[
D(m)\frac{B_\epsilon(m,6,x)}
{\binom{2m+\epsilon}{m}}
\]

and

\[
D(m)\frac{B_\epsilon(m+1,6,x)-B_\epsilon(m,6,x)}
{\binom{2m+\epsilon}{m}}.
\]

## Exact Newton certificates

Each polynomial in (3) was expanded in the integer Newton basis

\[
\binom{M}{a}\binom{x}{b}.
\]

The full degree-determining grid had \(30\cdot16=480\) points per
parity.  One additional grid layer in each coordinate produced zero
coefficients beyond (3).  Six points with both coordinates beyond
the interpolation grid were then evaluated directly for each of the
four polynomials; all 24 off-grid identities held exactly.

Every Newton basis element is nonnegative for \(M,x\ge0\), while
\(D(m)\) and the central binomial coefficients are positive.
Therefore the four nonnegative coefficient lists prove (1)--(2).
