## Design requirements

| Requirement | Status |
| --- | --- |
| At least two routes to each hostage area | ✔ Conference room has three; executive office has three |
| Short and medium-range combat | ✔ Cubicle pods, vestibule, stairwell, corridors |
| One or two controlled long sightlines | ✔ North Cross Corridor (48 m) and the lobby across the curtain wall |
| Recognisable landmarks | ✔ Vestibule glass box, brand wall, double-height lobby, mezzanine, stair void, garage shutter |
| Readable room transitions | ✔ Cased arches, glazed partitions and door types signal what is behind them |
| Logical architectural flow | ✔ Public → work → service → back-of-house, with plant on the perimeter |
| Chokepoints with alternate approaches | ✔ Vestibule (bypass via mechanical plant), stairwell (bypass via fire stair), mid-block corridor (bypass via concourse) |
| Naturally placed cover | ✔ Cubicles, filing runs, planters, reception desk, crates |
| Doors supporting tactical entry | ✔ 44 doors across 10 types; all AI-navigable |
| Windows and interior glass affecting visibility | ✔ 136 panes; clear glass is see-through to AI, tinted and frosted are not |
| Loops preventing a single hallway | ✔ Perimeter ring + central concourse + mid-block link, on both floors |
| Navigation space for player, enemies and hostages | ✔ 36 320 active nav cells, every room covered |
| No inaccessible visual promises | ✔ Every visible interior space is enterable; roof decks are clearly outside |
| No accidental dead ends | ✔ Every room reaches the lobby and the extraction garage, and back |
| No inconsistently climbable objects | ✔ 0.42 m step height applies to player and AI alike; nothing between 0.42 m and vaulting height reads as climbable |
| No gaps exposing the void | ✔ 24 rays × 3 pitches from every room terminate on geometry |
