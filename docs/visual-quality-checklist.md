# Visual Quality Checklist

Applied per room and per asset during Phase 6 passes. A room passes only when
every line is checked with screenshot evidence.

## Per-room checklist
- ☐ Purpose readable at a glance (real-world function obvious)
- ☐ Correct scale (doors 2.06m, desks 0.75m, ceilings per plan)
- ☐ Floor material correct + wear/decals where believable
- ☐ Walls: baseboards, trim, no razor edges on close-view corners
- ☐ Ceiling: grid/tiles/fixtures appropriate; no missing faces
- ☐ Lighting: readable, no crushed blacks, no blown windows, no leaks
- ☐ Cover reads naturally (not arena-placed crates)
- ☐ Landmark present (each room has one memorable feature)
- ☐ Signage/storytelling props coherent with Northstar Dynamics fiction
- ☐ No z-fighting, no floating props, no intersecting meshes
- ☐ No unfinished void visible from any player-reachable position
- ☐ Enemies readable against the palette at gameplay distances

## Per-asset gates (from prompt)
Silhouette ≥4 · Proportions ≥4 · Materials ≥4 · Texture ≥4 · Lighting ≥4 ·
Animation ≥4 (if any) · Integration ≥4 · Function ≥4 · Performance ≥4 ·
Bible-consistency ≥4

## Global image checks
- ☐ Palette follows the visual bible (cold exterior / neutral office / warm accents / dark-but-readable service)
- ☐ Exposure comfortable; vignette/bloom restrained
- ☐ AA on; shadows stable (no shimmer)
- ☐ HUD minimal, legible at 1080p and 4K
