# Visual Quality Checklist (Fable 1 gate)

Scored per the per-asset production loop (silhouette, proportion, materials, texture,
lighting response, animation, integration, function, performance, bible-consistency —
all must be ≥ 4/5). This file tracks *scene-level* quality gates.

## Global gates
- [ ] No placeholder/flat-shaded geometry anywhere
- [ ] Every exposed architectural edge chamfered; no razor edges in close view
- [ ] Roughness variation visible on every large surface; no uniform-gloss rooms
- [ ] No baked directional light in albedo textures
- [ ] No crushed blacks; darkest service corridor floor ≥ RGB(16,18,22) on screen
- [ ] No blown-out windows: exterior visible with snow + treeline, not white void
- [ ] Bloom restrained (only emissives bloom; no full-screen glow)
- [ ] Enemies readable at 25 m in every combat space
- [ ] Objective/danger/navigation color language consistent (gold/red/teal)
- [ ] No z-fighting, no light leaks, no floating props, no visible void
