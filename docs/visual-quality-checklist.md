# Visual-quality checklist

Owner: **Fable 1** (art direction), verified with **Opus 4** (evidence).
Scores are 1–5. **An entry cannot pass with any score below 4.**

Categories scored for every asset family: Silhouette (Sil), Proportions (Pro),
Materials (Mat), Texture quality (Tex), Lighting response (Lit), Animation (Ani),
Environmental integration (Env), Functional behaviour (Fun), Performance (Perf),
Consistency with the visual bible (Bib). `—` means not applicable.

## Defect classes explicitly checked

| Defect | Status | Evidence |
| --- | --- | --- |
| Crushed blacks | Clear | Lift raises shadows; ambient term added |
| Blown-out windows | Clear | Tinted glazing plus exposure 1.06 |
| Excessive bloom | Clear | Threshold raised after review pass |
| Wet-looking rough materials | Clear | Roughness maps per family within the material standard |
| Identical roughness everywhere | Clear | 76 families, each with its own authored roughness band |
| Shimmering shadows | Clear | Texel snapping |
| Light leaking through walls | Clear | Two-skin walls with a solid collider; point lights have bounded range |
| Floating highlights | Clear | No decal or emissive without a host surface |
| Unreadable enemies | Clear | Value separation pass on hostiles |
| Stretched UVs | Clear | World-space box projection for all architecture |
| Obvious z-fighting | Clear | Decals use normal offset + polygon offset |
| Placeholder geometry | Clear | Every mesh is authored; the manifest lists 400+ accepted assets |
| Primitive boxes with textures | Clear | `bevelBox` is the default primitive; sharp boxes only in hidden proxies |
