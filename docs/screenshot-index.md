# Screenshot Index (before/after evidence)

Curated evidence lives in `docs/screenshots/` (committed, 1280px JPEG).
Raw full-resolution QA output goes to `artifacts/` (gitignored). Room finals
were captured on the Audit 4 clean-pass tour (31 checkpoints, zero console
errors); weapon/character/UI/VFX evidence comes from the owning agents'
acceptance captures.
