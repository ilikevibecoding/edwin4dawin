# Final Checklists — Northstar Rescue

Evidence lives in `artifacts/` and is regenerated by `npm test`, `npm run shots`,
`node tools/audit.mjs` and `node tools/smoke.mjs`. Luminance figures are the mean of the rendered
frame at the room's checkpoint under production lighting, on a 0–255 scale; the readable floor for a
space the player fights in is **42** (`READABLE_LUMINANCE_FLOOR` in `src/art/palette.js`).

### Map-design requirements

| Requirement | How it is met |
| --- | --- |
| Two meaningful routes to each hostage | **Conference (A):** lobby → open office → west glass door, or cross corridor → loading bay → south fire door. **Executive office (B):** central stair → mezzanine gallery → executive door, or waiting area → west fire stair → stair head → executive door, or via the archive |
| Short and medium-range combat | Cubicle pods, break room, copy room, back-of-house rooms |
| One or two controlled long sightlines | Open-office central aisle (25 m, broken by cubicle ends and two columns); service corridor (28 m, broken by door frames and duct runs) |
| Recognisable landmarks | Brand wall and atrium columns, feature stair, glazed conference box, server room glow, garage shutter |
| Chokepoints with alternate approaches | Vestibule doors, lobby→office double doors, cross-corridor arches, dock opening — each has a second way round |
| Loops, not one hallway | Lobby → office → cross corridor → service corridor → loading → conference → east link → lobby closes a full circuit; the mezzanine adds a second vertical loop |
| No gaps to an unfinished void | Walls derived from room rectangles so shared edges always close; roof caps emitted per open-sky rectangle; verified by teleporting to every checkpoint |
| No accidental dead ends | Every room has two exits except the janitor closet and the restrooms, which are real single-door rooms |
| Doors support tactical entry | 27 doors with real swing, hardware, collision, sound and AI navigation |
| Glass affects visibility | 16 glazed openings; glass does not block sight, does block movement, and breaks with a fracture state |

### Weapon states with evidence

| State | Verified by |
| --- | --- |
| Draw / holster | `weapons-switch.json` — transitions block firing for the draw duration |
| Idle sway, movement sway | `fable4-weapon-after-office.png`; sway driven by look delta and velocity |
| Fire | `weapons-fire.json` — magazine decrements by exactly one per shot, recoil moves true aim |
| Aim transition | `weapons-ads.json` — FOV and spread change, sights align with screen centre |
| Reload with ammunition remaining | `weapons-reload.json` — chambered round retained |
| Empty reload | `weapons-reload.json` — no chambered round, bolt release plays |
| Magazine removal / insertion / chambering | Viewmodel `reload_tactical` and `reload_empty` clips |
| Dry fire | `weapons-fire.json` — fires nothing, plays the dry click |
| Recoil recovery | `weapons-recoil.json` — aim returns to ~90% of the accumulated climb |
| Landing response | Viewmodel landing dip on `EVT.PLAYER_LAND` |
| Inspect | Bound to `I`, does not block core actions |

### Animation states with evidence

Idle, breathing, walking, running, crouching, crouch-walking, turning, aiming, firing, reloading,
flinch, taking cover, investigating, searching and three death variations — plus hostage idle, fear,
crouch, follow, stop and extract. Captured mid- and end-frame in `fable4-anim-*.png` using the
deterministic capture path (rAF loop stopped, frames driven by `advanceTime`).

Checked and passing: consistent human scale, clean silhouette at 3 m / 10 m / 16 m / 20 m, believable
clothing layers, original insignia, material separation between fabric / armour / skin / rubber /
metal, weapon attachment with correct hand placement, hit regions with per-region multipliers
(head 4.0×, chest 1.0×, stomach 1.25×, limbs 0.75×), shadow casting, LOD swap at 18 m that is not
visible, no mesh separation during movement, and no weapon clipping through a face, arm or torso.
Garment albedos were lifted ~35% after the blackout lighting scenario made the hostiles disappear
entirely — they now stay readable without looking self-lit.
