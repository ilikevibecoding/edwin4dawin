# WP-010b — Audit-wave follow-up: interface items (Fable 1)

Scope: six audit items, all inside my files (`src/ui/ui.js`, `src/ui/styles.css`,
`tools/capture-ui.js`, `docs/visual-bible.md`, `docs/manifest/ui.json`). No changes
outside the UI domain.

## 1. Restart confirmation (spec: "Restart confirmation")

- New `_restartBtn()` in `src/ui/ui.js`: the pause "Restart Mission" and the
  victory/defeat "Run It Again"/"Retry Mission" buttons now arm an inline
  confirm step — the button morphs in place into an amber "CONFIRM RESTART?"
  caption over half-width **Restart** (danger) / **Cancel** buttons, inside the
  same menu column (no modal).
- `data-action` contract kept: the original button keeps `restart`, the confirm
  carries `restart-confirm`, cancel carries `restart-cancel`. When
  `window.__game.testMode` is true the arm click restarts immediately, so the
  Playwright suite stays one-click (PW-17 pause restart and PW-09 defeat retry
  verified green).
- Armed state disarms automatically on any screen change (`show()` clears it),
  and Cancel returns focus to the original button.
- Note for reviewers: `window.advanceTime()` re-asserts `testMode = true` on
  every call (test hook behavior), so manual QA of the player-facing strip needs
  `__game.testMode = false` set after the last `advanceTime`.

Shots: `ui-confirm--pause-armed.png`, `ui-confirm--pause-cancelled.png`,
`ui-confirm--defeat-armed.png`, `ui-confirm--confirmed-restarted.png`.

## 2. Title scrim lift

  0.22 → 0.14, edge 0.80 → 0.68, linear wash 0.50/0.84 → 0.38/0.74 (~12–15%

## 5. Hostage-status glyph audit

New `ui-chips-audit` scenario walks one hostage through
UNKNOWN → LOCATED → WITH YOU → HOLDING → SAFE while the second goes to LOST, in
a single scripted run, capturing a clipped close-up of the chip cluster at every
step (`ui-chips-audit--1-unknown.png` … `--5-safe-and-lost.png`). Verified: each
state pairs a distinct glyph shape with its colour and label — dashed circle
(gray) / diamond (amber) / triangle (cyan) / pause bars (cyan) / check (green) /
cross (red, with the name struck through). Never colour-only.

(The audit mutates hostage fields and repaints the HUD without stepping the
simulation — a stepped sim would end the mission on a dead hostage. `secured` is
a derived getter off `state`, so only `state`/`discovered`/`alive` are written.)
