- **Metalness note from wp-011 is resolved**: with `scene.environment` (RoomEnvironment @ 0.42)
  bare metals read correctly; galvanized/brushed values were restored (duct 0.55, flagpole 0.85,
  security door 0.6). Painted steel stays 0.3–0.45.
- **Normal-scale gotcha (worth knowing for other adopters)**: Fable 3 uses `paintedMetal` with
  `tiled: false` (0..1 stretched UVs), which visually dilutes the baked peel relief. At TRUE
  world tiling the same normal map reads as hammered iron. Structural adoptions run
  `normalScale 0.3–0.5`; surfaces inspected at arm's length (door leaves, entry portal,
  bollards) needed a further drop to **0.12** — 0.3 still read as stucco in
  `map-fix--door-fire.png` (18:24 capture). Verified in the final `map-fix--*` door shots.
- Dead placeholder names `snowDrift`, `snowCap`, `deckDark` removed (drifts/caps/deck consume
  the shared textured `snow`/`deck` directly).
- Emissive/glow + canvas signage materials untouched, per the brief.
- Monolith sign shrink-to-fit **verified fixed** (`map-fix--monolith.png`: both lines fit inside
  the border with margin). No proportion changes needed.

## 2. Door leaves

`src/map/doors.js`:

- Leaf boxes get **leaf-local `worldUVs()`** (offset to the hinge-side bottom corner) — kills
  the 2.3:1 vertical stretch of the default box UVs. Applied in local space because doors
  rotate (the `placeProps()` world-space retrofit rightly skips door subtrees; geometry is
  marked `worldUVsApplied` for belt and braces).
- New textured styles: standard/wide/restroom → `doorPaintTex`, fire → `doorFireTex`,
  security → `doorSecurityTex` (shared `doorPaint`/`doorFire`/`doorSecurity` are still flat —
  not my file). Wood doors keep Fable 3's `doorWood`, now tiling correctly via the UV fix.
- Tints run one step darker than the target read (fire 0x6b332c, painted 0x79828b): the
  office/service fills overexpose wall-plane surfaces ~1.5-2x, which had the fire door reading
  salmon and the security door reading white in the first capture round.
- **Security leaf needed hue, not value** (found via a magenta-paint probe on the live leaf):
  at the server-door head the IT-corner troffer fill + colorless specular dominate the diffuse
  term, so ANY neutral dark gray washes to wall-white — only hue survives the blowout, exactly
  like the fire door's red does. Final: saturated steel-blue 0x31435a with metalness 0.06
  (specular cut) — reads as a distinct blue-steel security leaf under the same light.
- **Kick plates** (brushed, 0.24 m, both faces) on all painted/fire/security leaves.
- Shutter slats get panel-local `worldUVs` (continuous paint texture across slats instead of
  one stretched copy per slat).
- Handles/pushbars/hinge animation/collider untouched — `doors` scenario green (below).

## 3. Server room mood

`lightplan.js` + `ceilings.js` + `finish.js`:

- Zone `server`: intensity 28 → 9, fixture density `every` 10 → 18, color deeper blue-cyan
  (0x7fc0e4). Rack-glow accents boosted (20/18, 0x54c4e8) so the rack LEDs + accents carry the
  room; hemisphere keeps silhouettes readable. (First pass at 14/15 still read bright —
  18:26 capture — so it went one step further.)
- Server strips use a new dimmer/cooler lens material (`fixtureLensServer`, emissive 0.85)
  instead of the shared bright `fixtureLensCold`.
- **New `ARCH-SERVER-LINER`**: lighting alone couldn't deliver the visual-bible "cool dark data
  center" — the shell walls are pale `exteriorPanel`/`concretePaint` faces (not my materials).
  Thin dark tech panels (22 mm, `panelSet` tinted 0x2a333d) now line the inside faces, door
  spans skipped, no collider (wall AABBs behind them). Props flush against server walls may
  sink 22 mm into the liner — cosmetic, flagged below.
- **Server floor darkened**: the stock white `raisedTile` blew out under any fill level and
  kept the room clinical. New `raisedTileDark` (same access-floor set, tinted 0x6d7880);
  `layout.js` server `floorMat` switched to it — a **visual-only room attribute** change,
  explicitly allowed by the graybox lock (rects/openings untouched). `builder.js#floorCollMat`
  matches the new name to the same `tile` collision material, so footsteps are unchanged.
- Enemy readability verified with a live (frozen, not killed) guard in frame:
  `map-fix--server-mood.png`.

## 5. Atrium skylight shaft

New `ARCH-SKYLIGHT-SHAFT` (atrium.js#lightShafts): three additive alpha sheets along the
lightplan sun vector, vertex-color faded toward the floor, depth-clipped by the feature
wall/mezzanine so the beam lands where the real sun patch falls. Unlit + `fog: false`,
opacity 0.05, no colliders, one draw call (transparent, intentionally unmerged).

  the visual bible.

  `raisedTileDark`. No rects/openings/stair topology touched.

  (`map-fix--horizon-south.png`) — emissive + post bloom halo; reads as glow through storm
  fog at gameplay distances, left as-is.
