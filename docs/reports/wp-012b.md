# WP-012b — Props & Materials completion pass (Fable 3)

Status: complete. All nine items from the follow-up list are implemented and verified inside the
Fable 3 file set (`src/materials/**`, `src/props/**`, manifests, `tools/capture-props.js`).
Everything remains procedural — no external asset files.

## 1. Plants (flora card system)

New module `src/props/flora.js`: one 256 px cutout atlas (canvas-drawn) with three species
silhouettes — ficus canopy (golden-angle leaf scatter over twigs), snake plant (upright tapering
blades with pale margins + banding), fern (arching fronds of shrinking leaflets). One shared
`MeshStandardMaterial` (`alphaTest 0.4`, DoubleSide) so every plant in a zone merges into a single
cutout draw; alphaTest keeps the cards in the opaque pass and three.js' shadow-depth variants
honour it, so no rectangular card shadows.

Library upgrades (`src/props/library.js`):

- `floorPlant` is now a proper ficus: pot + soil + trunk + 5 crossed canopy cards in two tiers
  (was: three green spheres). Every existing call site upgraded automatically.
- New `snakePlant` (PROP-PLANT-SNAKE, collider) and `fernPlant` (PROP-PLANT-FERN) parametric
  builders with a scale param for desk/counter use.
- `deskPlant` now picks fern or snake mini-cards deterministically from world position.
- `planterPlants` fills Fable 2's ARCH-PLANTER boxes (all 6: vestibule flank x2, feature wall x2,
  mezz rail x2) with an alternating snake/fern row at soil height (+0.44) — was leaf-sphere blobs.
- New placements for species variety: waiting-lounge east window (snake), copy-room desk (fern),
  HR filing cabinets (fern), quiet-room table (fern), break room window (snake), assistant filing
  cabinets (fern).

Evidence: `artifacts/shots/rooms--entrance.png` (planters flanking the vestibule doors),
`rooms--lobby-planters.png` (feature-wall planters + mezz ficus), `rooms--wait.png` (ficus pair),
`rooms--break-kitchen.png` (snake plant).

## 9. Materials polish for the env map

With RoomEnvironment PMREM (intensity 0.42) present, the pre-envmap roughness compensations on
bare metals were removed (`src/materials/index.js`):

| material | before | after |
|---|---|---|
| stainless | rough 0.8 | 0.42 (satin) |
| aluminum | rough 0.8 | 0.5 |
| brushedMetal | rough factor 1.0 | 0.85 (over the brushed map) |
| chrome | 0.12 | 0.16 (subtle, no mirror-world) |
| mirror | 0.05 | 0.06 (near-mirror by design) |

Verified on the break-room appliance run, restroom mirrors/faucets and the van wheels in the tour
shots — metals read as metal now without hot mirror highlights.
