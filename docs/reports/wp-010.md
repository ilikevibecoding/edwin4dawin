# WP-010 — Interface art direction & visual bible (Fable 1)

Scope: full pass over the DOM/CSS interface layer — title treatment, menu suite,
HUD, end screens — plus ownership handover of `docs/visual-bible.md` (now v2).
No changes outside `src/ui/**`, `docs/visual-bible.md`, `docs/manifest/ui.json`,
`tools/capture-ui.js`, and this report.

## Changes

### `src/ui/styles.css` — token system + chrome (rewritten)

- Authoritative token set (documented in the visual bible): ink ramp
  (`--ink/--ink-dim/--ink-faint`), surface ramp (`--bg-deep/-panel/-panel-lite/
  -inset/-hud`), edge ramp, and four semantic accents (`--accent` cyan,
  `--accent-warm` amber, `--danger` red, `--ok` green).
- Panel chrome: 45° corner cuts (top-left + bottom-right) built as a 1px gradient
  shell + clipped `::before` fill so hairlines survive the clip; backdrop blur on
  panels/pause only (cheap surfaces), never on HUD.
- Buttons: cut corners, gradient face, edge-lit hover/focus-visible state, staggered
  `btn-in` entrance; `.primary` variant carries the accent gradient.
- Motion policy: every animation collapses under `body.reduced-motion` (mirrors the
  settings toggle), the OS `prefers-reduced-motion` query, and `body.ui-static`
  (added when `?test=1` — keeps automation deterministic on software renderers).

### `src/ui/icons.js` — original SVG icon program (rewritten)

- `titleLogotype()` — layered NORTHSTAR wordmark (glow / stroke / gradient fill),
  compass-star emblem with elongated north point breaking the cap line, RESCUE
  strip with amber diamonds, tagline, drifting tick ring.
- `weaponIcon()` — 8 original side profiles (Karst P9, Boreal K5, Halcyon HC-4,
  Vanta S-12, Meridian LR-8, Fieldman CQ, FB-3 flash, SG-2 smoke), 140×48,
  fill-layered (`wl-body/wl-dark/wl-line`), muzzle-right on a common centreline.
- `difficultyInsignia()` — shield lockups: chevron (Recruit), northstar (Operator),
  triple chevron (Veteran) — shape-coded, tinted per card accent.
- `chipGlyph()` — one shape per hostage state (dashed circle / diamond / triangle /
  pause bars / check / cross) so colour is never the only signal.
- `starLogo()` — 24-tick compass ring reused as the boot/loading spinner.

### `src/ui/ui.js` — screens (restructured, same class API)

- Title: logotype over the live scene, radial scrim + cinematic bars, seeded
  110-flake snow canvas (runs only while the title is visible; off under
  reduced-motion), station corner tag, credits/version footer.
- Settings: grouped sections (Controls / Video / Accessibility / Audio) with live
  mono value chips and a control-reference grid.
- Difficulty: three insignia cards with per-tier accent (cyan/amber/red), threat
  pips, hover lift; identity differs by insignia shape, not colour alone.
- Briefing: classified-dossier layout — header band with REF number, CLASSIFIED
  stamp, lead paragraph hierarchy, OBJ-xx list, blueprint schematic plate.
- Loadout: presentation stage per weapon card, EQUIPPED flag, DMG/ROF/RNG bars,
  mag/action metadata row, standard-equipment chips for sidearm/devices.
- Loading: spinning compass ring + FIELD NOTE tip (rotates via `cosmeticRng`).
- Pause: radial vignette veil over the frozen world.
- End screens: victory = cold-blue wash + gradient banner; defeat = red-washed
  treatment with tinted rules; both with mono stat strips (time/kills/accuracy).
- HUD: vitals (quarter-tick bars, hurt state ≤35 HP), ammo (32px mono counter,
  amber low / blinking red empty, slot dots, weapon silhouette), objectives
  (pulsing active box, green check + strike on completion), hostage chips (all six
  states), mission clock, interaction prompt (kbd glyph + label), 16px subtitle
  plate, subtle hit/kill markers, damage vignette + conic direction arc, flash
  whiteout, LR-8 scope overlay (rings, 7-mil cross with numerals, inset vignette),
  spread-driven crosshair (dot variant class ready).
- `_registerAssets()` registers all 30 `UI-*` asset IDs.

### `src/ui/minimap.js` — cartography

### `tools/capture-ui.js` — new capture harness (my scenarios)

Scenarios: `ui-title`, `ui-settings`, `ui-menus` (difficulty + hover + briefing +
4 loadout selections), `ui-loading`, `ui-hud` (idle / firing / ammo-low / ammo-empty /
subtitle / damaged / vitals-critical / flash), `ui-scope`, `ui-hostages` (unknown /
located / with-you), `ui-pause`, `ui-end` (victory + defeat), `ui-small` (1366×768

fallback for when Playwright's font-wait preamble stalls under load.

## Contrast notes

Computed against the HUD plate `--bg-hud` rgba(6,11,17,.62) over a worst-case
bright snow backdrop (effective ≈ #4e565e):

- `--ink` #eaf2f8 → ≈ 12.7:1 (AAA) — all primary HUD text.
- `--ink-dim` #a7bccc → ≈ 8.0:1 (AA+) — labels, secondary text.
- `--ink-faint` #64798a → ≈ 3.4:1 — decorative metadata only, never load-bearing.
- `--accent-warm` #e8b45f on plate → ≈ 8.9:1; `--danger` #e05545 → ≈ 4.6:1 (paired
  with blink + shape, never colour-only).
- Every piece of text over the 3D scene sits on a plate; subtitles are 16px on
  rgba(4,8,13,.66).
- Colorblind safety: hostage states, objectives, ammo warnings, minimap markers,
  and difficulty tiers all pair colour with a distinct shape or motion cue.

## Known issues

- The shared CI box frequently runs several software-rendered Chrome instances at
  once; frame production can stall for tens of seconds and Playwright's screenshot
  preamble ("waiting for fonts") can hang even though no web fonts exist. My
  harness works around this (long timeouts, forced interactions, CDP screenshot
  fallback), but under peak load a scenario can still take minutes.
- The damage vignette/direction arc fade on 350/900 ms wall-clock timers, so the
  `damaged` capture re-arms them explicitly; in real play the timing is correct.
- Crosshair style options: the `.ch-dot` variant class is implemented and themed
  but not yet surfaced in settings (needs a settings key owned by game code).
- Backdrop blur is used on menu panels and the pause veil only; it is disabled in
  `body.ui-static` (test mode) because SwiftShader renders it very slowly.
