# Asset Manifest — Northstar Rescue

**Source of truth:** every production asset must call `registerAsset()` in
`src/assets/registry.ts` at creation time with its full manifest record. An asset that
is not registered cannot appear in the game (builders go through the registry). This
file is the human-readable export, regenerated by `npm run manifest` (tool:
`tools/export-manifest.mjs`), which launches the game headless, collects the runtime
registry, and rewrites the table below. **Do not hand-edit below the marker.**

## Record schema (all fields required per prompt)

- `id` — unique asset ID (e.g. `prop.desk.standard`)
- `name` — human-readable name
- `category` — architecture | door | glass | furniture | electronics | breakroom |
  restroom | maintenance | clutter | signage | material | decal | character | weapon |
  vfx | ui | audio
- `agent` — responsible role (Opus 1–4 / Fable 1–4)
- `files` — implementing module(s)
- `where` — intended rooms / game states
- `dims` — physical dimensions (m, W×D×H) or n/a
- `pivot` — pivot & orientation convention (default: floor-center, +X facing front)
- `materials` — material slots used
- `textures` — texture maps used (procedural generator IDs)
- `collision` — none | static-aabb | static-mesh | dynamic | trigger
- `lod` — merged-static | instanced | none | billboard-far
- `anim` — animation states, if applicable
- `audio` — audio dependencies (synth patch IDs), if applicable
- `status` — spec | built | integrated | inspected | **accepted**
- `accept` — acceptance criteria summary
- `evidence` — Playwright screenshot path(s)
- `notes` — remaining discrepancies

Defaults (apply unless a row overrides): pivot = floor-center front=+X; collision =
static-aabb; lod = merged-static; anim = none; audio = none.
