## B. Proved here (rigorous, machine-checked)

Full statements and proofs: `docs/REDUCTION_LEMMA_AND_PROVED_CASES.md`;
symbolic checks: `scripts/verify_lemmas_symbolic.py`; tests: `tests/`.

1. **Reduction lemma.** For `r >= 1`, `p_{r-1} > 0`: `WR_r`, `ISO_r` and a
   descent `p_r <= p_{r-1}` imply `p_{r+1} <= p_r`, via the identity
   `r p_r^2 - (r+1) p_r p_{r-1} + p_{r-1}^2 = (r p_r - p_{r-1})(p_r - p_{r-1})`.
2. **Conditional unimodality theorem.** `WR_r` and `ISO_r` for
   `1 <= r <= L(alpha)-1` plus the Levit–Mandrescu tail theorem imply
   unimodality. So the handoff's architecture is sound; the entire difficulty
   is the universal `ISO` theorem.
3. **`ISO_1`, `ISO_2`, `WR_1`, `WR_2` hold for every forest.** With `n`
   vertices, `e` edges and `S = sum_v C(d_v,2)`:
   `p_2 = C(n,2) - e`, `p_3 = C(n,3) - e(n-2) + S`, `Q_1 = n + 1 + 2e`, and
   `Q_2 >= 2(C(n,2)-e)^2 + n^2 - 3n(C(n,3) - e(n-2) + C(e,2))`, which is
   concave in `e` with positive endpoint values `n^2(n-1)/2 + n^2` (`e = 0`)
   and `(n-1)(n-2) + n^2` (`e = n-1`).
4. **`ISO` is asymptotically tight at `r = 2`.** On the star `K_{1,n-1}`,
   `Q_2 = (n-1)(n-2) + n^2` while `p_1 p_2 ~ n^3/2`, so the dimensionless
   margin `Q_2/(p_1 p_2) = 2/n + 2n/((n-1)(n-2)) -> 0`. Exhaustively, the
   star is the unique minimiser of the margin for every order checked. Any
   inductive "payment" proof must therefore be exact (not merely
   nonnegative) on stars at `r = 2`; there is no slack to absorb errors.
5. **Real-rooted case.** If `I(F;x)` is real-rooted (e.g. `F` claw-free, in
   particular every path), Newton's inequalities give `ISO_r` at every index.

## D. What remains open, and an assessment of the plan

- The open core is the **all-forest `ISO_r` theorem for `r >= 3`** (or the
  weaker descent-conditional form: `ISO_r` at prefix indices where
  `p_r <= p_{r-1}`). Already `ISO_3` needs `p_4`, which involves
  `sum_v C(d_v,3)` and the number of induced `P_4`s; dropping those terms
  fails near the star, so each further index is a genuine degree-sequence
  optimisation — consistent with the handoff's "rank" structure where every
  coefficient was a separate campaign. Empirically the margins for `r >= 3`
  stay above `~0.87` (double brooms, `r = 4`, `n -> infinity`), so there is
  slack there, unlike at `r = 2`.
- The handoff's Gate 5 still lists: rank-6 `G1` (three coupled families, all
  strongest cones infeasible), all-`N6` integration, rank-6/7 propagation,
  and the Newton join for indices `m = 0..7`. Even taking every frozen claim
  at face value, that is several independent unproved theorems, not a
  finishing step. The realistic status is the handoff's own last sentence:
  substantial exact progress, theorem still open.
- Literature (see `docs/LITERATURE_STATUS_2026-09-02.md`): no proof and no
  counterexample is known; unimodality is verified for all trees with
  `n <= 29` (Reynolds et al.); log-concavity fails from `n = 26`
  (Kadrawi–Levit–Yosef–Mizrachi); `T_{3,m,n}`, `T*_{3,m,n}` are proved
  unimodal (arXiv:2603.03025).
