## 3. Exact results

Throughout, *prefix* means `1 <= r <= L(alpha) - 1` with
`L(alpha) = ceil((2 alpha - 1)/3)`; the descent argument of the handoff uses
`WR_r` and `ISO_r` only there. Every finite result below is **falsification
evidence only** (handoff Rule 4).

Scope note on `TAIL` (from the literature audit): the decreasing-tail theorem
`p_r >= p_{r+1}` for `r >= L(alpha)` is Levit–Mandrescu, *Partial
unimodality for independence polynomials of König–Egerváry graphs*, Congr.
Numer. 179 (2006), stated for König–Egerváry graphs — which include every
bipartite graph, hence every forest — **not** for arbitrary graphs (the
general-graph analogue is Basit–Galvin 2021, Theorem 3, with cutoff
`ceil(alpha (n-1)/(alpha+n))`). The framework only needs the forest case, so
the reduction is unaffected; any wording "for all graphs" in this directory
should be read as "for all forests".

### 3.2 The `WR + ISO + TAIL` reduction

Exact identity `r x + 1/x - (r+1) = (r x - 1)(x - 1)/x`, and the
division-free engine (sympy-expanded to 0)

```text
(r+1) p_{r-1} (p_r - p_{r+1}) = Q_r + (r p_r - p_{r-1}) (p_{r-1} - p_r),
```

whose right side is `>= 0` under `ISO_r`, `WR_r` and a weak descent
`p_r <= p_{r-1}`; hence `p_{r+1} <= p_r`.

Lemma (proved in `WR_ISO_TAIL_LEMMA.md`): positive integers `p_0..p_alpha`
with `WR_r`, `ISO_r` for `1 <= r <= L-1` and `p_r >= p_{r+1}` for
`L <= r <= alpha-1` form a unimodal sequence; sharper: either no weak descent
occurs in the prefix (then `p` is strictly increasing on `[0, L-1]`,
non-increasing on `[L, alpha]`, mode `L-1` or `L`), or the first weak descent
is at `r_0` and `p_0 < … < p_{r_0-1} >= p_{r_0} >= … >= p_alpha`. All edge
cases handled (`alpha <= 2`, empty prefix, plateaus, hand-off at `r = L-1`,
positivity via subsets of a maximum independent set). Not needed: `ISO` in
the tail, `WR` for `r >= L`, log-concavity (the KLYM tree `T1` has `WR_13`
and `WR_14` failing and log-concavity failing at `r = 13`, all in the tail,
while the hypotheses hold on its prefix `r = 1..8`).

Replay (`replay_wr_iso_tail_logic.py`, marker
`PASS_WR_ISO_TAIL_LEMMA_REPLAY`): hypotheses and conclusion verified on all
15,205 forests `n <= 14`; 100,000 seeded random positive sequences satisfying
the hypotheses are all unimodal (equality edges exercised); dropping a single
`ISO_r` (or `WR_r`) in the prefix produces non-unimodal sequences (smallest
`(1,2,1,2,1)` resp. `(4,1,2,1)`), so both hypotheses do work. Sharpness: for
the edgeless forest the `ISO` ratio is `1 + (n+1)/((n-r+1)(n-r))`, so no
uniform constant `> 1` is possible; the star has `Q_2 = 2m^2 + m + 1` and
ratio `1 + 4/m^2 + 10/m^3 + O(m^{-4})`; the cutoff `L` cannot be lowered (for
`alpha in {1..6, 8}` some forest has its first mode exactly at `L(alpha)`),
and raising it would require `WR` beyond `L`, which fails.

### 3.3 `ISO_2` for every forest (exact theorem)

For a forest with `n` vertices, `e` edges and `S = sum_v C(d_v,2)`:
`p_1 = n`, `p_2 = C(n,2) - e`, `p_3 = C(n,3) - e(n-2) + S`, and

```text
Q_2 >= f(n,e) = n^2(n+1)/2 + e(n^2 - 5n/2) + e^2(2 - 3n/2),
```

which is concave in `e` with `f(n,0) = n^2(n+1)/2` and
`f(n,n-1) = 2n^2 - 3n + 2 > 0`; `Q_2 - f(n,e) = 3n (C(e,2) - S) >= 0` with
equality iff the edge set is a star. Hence **`Q_2 >= 2n^2 - 3n + 2 >= 1` for
every forest**, with equality iff `F = K_{1,n-1}` (`Q_2 = 2m^2 + m + 1`,
`m = n-1`; `ISO_2` ratio `1 + O(1/m^2)`). Corollary: `WR_2` ⟺
`2e <= n(n-2)`, true for every forest with `n >= 4` (fails only for `K_1`,
`K_2`, `P_3`), and `r = 2` is a prefix index iff `alpha >= 4`, which forces
`n >= 4`. Marker `PASS_EXACT_ISO2_ALL_FORESTS` (12 sympy identities; every
step also checked on all 15,205 forests `n <= 14`). The proof uses no
enumeration.

### 3.4 `ISO_3` for every forest (exact theorem)

With `M2 = C(e,2) - S`, `T = sum_v C(d_v,3)`, `P4 = sum_{vw in E}(d_v-1)(d_w-1)`:
`p_4 = C(n,4) - e C(n-2,2) + (n-3) S + M2 - P4 - T` (inclusion–exclusion over
edge subsets; forests have no cycles), and

```text
Q_3 = n^2(n-1)^2(n+1)/12 + n(n-1)(n-2)(n-9)/6 · e - (n+1) e^2 + 2 e^3
      + 3 S^2 - (K S - M T) + M P4,
K = n(n-1)(n-6) + 2(n+2) e,   M = 4 p_2 = 2n(n-1) - 4e > 0  (n >= 3).
```

`K S - M T = sum_v (d_v - 1) h(d_v)` with `h(d) = d(3K + 2M - M d)/6 <= phi :=
(3K+2M)^2/(24M)` (completed square), and `sum_{d_v >= 1}(d_v - 1) = e - c' <=
e - 1` for `e >= 1`; `phi` is increasing in `e`, so `phi <= C_n :=
(n-1)(n-2)(3n-2)^2/48`. Dropping the nonnegative terms `2e^3`, `3S^2`, `M P4`
gives `Q_3 >= B_n(e) := n^2(n-1)^2(n+1)/12 + n(n-1)(n-2)(n-9)/6 · e -
(n+1) e^2 - (e-1) C_n`, concave in `e`, with `B_n(1) > 0` for `n >= 5` and
`B_n(n-1) = (n-1) β(n)/48`, `β(n) = 3n^3(n-16) + 92n^2 - 80n + 32 > 0` for
`n >= 14` (`β(13) < 0`). The 6,606 forests with `n <= 13` are checked
exhaustively (a finite, exact statement, not a collar). **Hence `Q_3 >= 0` for
every forest, with equality only for `K_1`, `K_2`.** Marker
`PASS_EXACT_ISO3_ALL_FORESTS` (21 sympy identities; the whole inequality chain
re-checked in exact rationals on all 85,624 forests `n <= 16`). I re-derived
identity (B), `c(d) = (d-1)h(d)`, the completed square, `phi(n,n-1) = C_n`,
`B_n(1)`, `B_n(n-1)` and `β(13..16)` independently in a separate sympy session
before accepting the theorem.

Explored only (`n <= 16` data): the `Q_3` minimiser is not the star but the
subdivided double star `T(⌈(n-3)/2⌉, ⌊(n-3)/2⌋)` (two star centres joined to a
common vertex), all candidates being `n^5/12 + O(n^4)`; the minimal `ISO_3`
ratio over prefix forests (`alpha >= 6`) is the edgeless forest for `n <= 11`
and a star plus 2–3 isolated vertices for `12 <= n <= 16`, decreasing to 1.

Relation to the frozen chain: these two theorems are the `r = 2, 3` cases of
the all-forest `ISO` statement, proved by elementary subgraph-count expansion
rather than by the bundle induction. They are independent of, and do not
depend on, the rank-4/5/6 machinery; if the handoff's rank-four theorem
`N_4(B;u,v) >= 0` implies `ISO_3`, this is an independent confirmation of that
consequence. The general prefix index `r` remains open.

Reading: the `1 + O(1/n^2)` tightness of the `ISO` target is attained by the
star at `r = 2`, an *ascending* index where the descent argument never
invokes `ISO`. At every prefix *descent* index (the only place `ISO_r` is
used) the observed ratio stays `>= 1.248` on the collar (attained by edgeless
or near-edgeless forests, decaying like `1 + O(1/n)`), and there the plain
log-concavity ratio `p_r^2/(p_{r-1} p_{r+1})` stays `>= 1.2375` (edgeless
forest, `n = 18`, `r = 10`); at a descent `LC_r` alone already implies
`ISO_r`.

Consequently, for any `c >= 0`, the unconditional inequality

```text
GATED_r^{(c)}:  Q_r + c p_r (p_r - p_{r-1}) >= 0
```

supports the same unimodality argument (at a descent it implies `ISO_r`),
while being weaker than `ISO_r` in the ascending part. On the collar it holds
with `c = 1` and roughly ten times the normalised slack of plain `ISO`
(0.209 vs 0.016 at `n = 18`); the collar admits any `c` up to ~6.75 at
`n = 18` (decreasing with `n`). This is offered as an **option for the open
Gate 5** — a different, still-unconditional polynomial target for the
rank-six `G1` payment — not as a change to any certified gate. Whether the
bundle machinery closes more easily on `GATED` than on `ISO` is untested.

### 3.7 Scope lemma (handoff §8.4): adjacent `k00` is empty

`SCOPE_LEMMA_ADJACENT_K00.md` proves: (A) for a forest `H` and a new vertex
`p` adjacent to `S ⊆ V(H)`, `H + p` is a forest iff `S` contains at most one
vertex of each component of `H`; (B) if `uv ∈ E(H)` and `u, v ∈ S` then
`p-u-v-p` is a triangle, so the adjacent geometry with both marks deleted
(`k00`) is impossible; (C) nonadjacent `k00` forces `u`, `v` into different
components.

Exhaustive partition census, every nonisomorphic forest `H` of order 2..10,
every ordered mark pair, every attachable `S` (1.6 M instances at `n = 10`;
the equivalence (A) checked against all `2^n - 1` subsets by two different
acyclicity tests): adjacent-`k00` count is `0` at every order; the other
seven cells are all realised, with minimal witnesses at orders 2–3
(`adjacent k11`: `H = P_3` centred at `u`, `S = {leaf}`; `nonadjacent k11`:
`H = P_3`, `u, v` the two leaves, `S = {centre}`).

Markers: `PASS_EXACT_SCOPE_LEMMA_ADJACENT_K00_PRODUCER` and
`PASS_INDEPENDENT_SCOPE_LEMMA_ADJACENT_K00` (separately written auditor,
networkx generator, DFS cycle test; all nine per-order tables identical).
