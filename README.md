# Nereid-4 — Walkable Submarine Interior

First-person walkthrough of an original deep-sea expedition submarine. Built with Vite, Three.js (`WebGLRenderer`), and Playwright screenshots.

```bash
npm install
npx playwright install chromium
npm run dev
npm run shots
```

Walk with WASD, look with the mouse, press E to interact.

Interactions:

- Sonar console — active ping
- Crew bunk — rest cycle
- Aft machinery panel — silent running
