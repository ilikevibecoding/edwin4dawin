# Starfall — The Stolen Design

An original, fully procedural, browser-based interactive cinematic that stages the opening
situation of *Star Wars: A New Hope* — a stolen weapon design, a diplomatic corvette that cannot
outrun what is behind it, and one unarmed droid carrying everything that matters.

Roughly **6 minutes 20 seconds** across eight chapters, rendered live in Three.js. Every mesh,
texture, animation, camera move, music cue, sound effect and narration line in this project is
generated by this repository's own code and tools. No film footage, model, texture, recording,
score or dialogue is reproduced, and no performer's voice is imitated. See
[docs/ASSETS_AND_LICENSING.md](docs/ASSETS_AND_LICENSING.md).

## Quick start

```bash
npm install          # Node 20+ (developed on Node 22)
npm run dev          # http://127.0.0.1:5173
```

Then click **Enter the Galaxy**. Browsers require a user gesture before audio can start, so that
button is also what unlocks the Web Audio context.

### Other commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Vite dev server on `127.0.0.1:5173` |
| `npm run build` | Type-check, then emit a production build to `dist/` |
| `npm run preview` | Serve the production build on `127.0.0.1:4173` |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run narration` | Re-render the narration audio from `src/content/narration.json` (needs Python, `piper-tts`, `ffmpeg`) |
| `npm run qa` | Automated visual tour: 29 checkpoints, screenshots, assertions, console-error capture |
| `npm run qa -- --controls` | The above plus a full interface exercise (play/pause, scrub, chapters, quality, explore, resize) |
| `node scripts/qa-audio.mjs` | Audio smoke test: proves each beat reaches the master bus and nothing clips |
| `node scripts/render-video.mjs` | Render a deterministic MP4 of any time range straight from the engine |

The narration MP3s are committed under `public/audio/narration/`, so `npm run narration` is only
needed if you change the script. There is no network dependency at runtime and no API key
anywhere in this repository.

Two modes:

- **Cinematic** — the piece plays itself: 29 directed shots, narration, score, effects, captions.
- **Explore** — the timeline pauses, the camera is yours. Orbit, fly, click any ship, droid or
  character for a short dossier, then Follow, Inspect, or return to the cinematic camera.

## Project layout

  main.ts                 entry point, WebGL check, top-level error boundary
  app/App.ts              application root: owns renderer, scenes, clock, audio, interface

## Performance

Three quality presets (Low / Medium / High) control pixel ratio, shadows, bloom, grain, particle
budgets, hull greeble density, star count, planet tessellation and anisotropy. A short startup
probe inspects the GPU string and device profile and *suggests* a preset; you can override it at
any time from **Settings**, and switching rebuilds both scenes against the new budget and releases
the previous GPU payload.

Targets: 60 fps at 1080p on a normal discrete GPU, comfortably usable at 30 fps on integrated
graphics at the Low preset. The automated tour in this repository runs against SwiftShader (pure
software rasterisation, no GPU at all) and still completes every checkpoint; frame rates quoted in
`qa/report.json` come from that software path and are not representative of real hardware.

## Testing

- `docs/QA_CHECKLIST.md` — the full manual and automated checklist, with results.
- `docs/CHECKPOINTS.md` — the screenshot checkpoint manifest (also machine-readable in
  `src/qa/checkpoints.ts`).
- `qa/report.json` — the last automated tour: per-checkpoint assertions, luminance measurements,
  subject screen coverage, console errors, control results.
- `qa/screenshots/` — one PNG per checkpoint.

Runtime sanity checks run continuously (and exhaustively during the tour) for NaN transforms,
objects outside expected bounds, cameras inside geometry, characters off the deck, missing
narration assets, particle-pool overflow, WebGL errors, console errors and sustained frame drops.
