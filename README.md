# Abyssal Surveyor

First-person walkthrough of an original deep-sea expedition submarine interior.

Procedural geometry and canvas-generated materials. No downloaded assets.

```bash
npm install
npm run dev
npm run shots
```

Click the canvas to look. WASD to walk. E to interact.

- Sonar console: active ping
- Crew bunk: rest cycle
- Aft machinery panel: silent running
