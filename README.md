# Deck 4 preview — Agent D (hangar + ship systems)

Static build of the Deck 4 dev harness from `cursor/sd-hangar-systems-c071` @ 203fdf3d: the main hangar,
four side bays, lobby, two corridors, stairwell and control tower, with the doors, turbolift and fighter
traffic systems running on D's registry shim (A's scaffold and exterior hull are not on the integration
branch yet, so the exterior views show the hangar block alone). Generated files only — do not edit here.

Open: https://raw.githack.com/ilikevibecoding/edwin4dawin/cursor/sd-hangar-systems-play-c071/index.html

Controls: click to take the deck · WASD move · mouse look · E interact (doors auto-open, lift call panel
and deck picker 1–4, stair totems) · F3 stats. URL options: `?spawn=<room-id>` (d4-hangar, d4-lobby,
d4-fighter-bay, d4-shuttle-bay, d4-cargo-bay, d4-repair-bay, d4-corridor-east, d4-corridor-west,
d4-stairs, d4-control), `?only=a,b` / `?skip=a,b` to load a subset of modules.

Preview on D's own branch, separate from the integrated build; A may delete it once that is up.
