# LEGO STAR WARS — A New Spark

A four-minute animated short where **every asset is generated by code**. There
are no modelling packages, no imported meshes, no image files, no audio files,
no music library and no stock sounds anywhere in this repository. Bricks,
minifigures, starships, planets, explosions, the orchestral score, thirty-odd
sound effects and the narrator's voice are all synthesised from source.

```bash
npm install
npm run dev          # open the page, press Play — sound on
```

## What it is

Seven scenes, 4:03, narrated end to end:

| # | scene | what happens |
| - | ----- | ------------ |
| 0 | crawl | the card, the logo, and a yellow crawl receding into space |
| 1 | chase | a corvette runs; a Star Destroyer arrives and keeps arriving |
| 2 | boarding | the corridor firefight, and who walks in through the smoke |
| 3 | pod | the plans go into a droid, and the droid goes out of the ship |
| 4 | tatooine | twin suns, two droids, one sandcrawler |
| 5 | trench | thirty pilots against a moon |
| 6 | finale | the exhaust port, the jump to lightspeed, the title card |

The story text is original; the narration was written for this project.

## How it is built

### Bricks

`src/lego/bricks.js` is a LEGO construction kit at real proportions — one world
unit is one stud pitch, a plate is `0.4`, a brick is `1.2`, a minifigure is
exactly `5.0` tall. Everything else is assembled from `brick`, `plate`, `tile`,
`slope`, `wedge`, `prism`, `cyl`, `cone`, `dish` and `bar`, anchored on a
consistent convention: centred on X/Z, resting on `y = 0`, facing `-Z`.
Finished static models go through `bake()`, which merges every mesh sharing a
material into one, taking a 400-brick Star Destroyer from hundreds of draw
calls to a handful.

### Printed detail

`src/lego/svgtex.js` rasterises SVG strings into textures. Every printed
element in the film — minifigure faces, Vader's chest box, stormtrooper
armour, R2's panels, hull markings, cockpit displays, the imperial gunner's
reticle — is authored as SVG markup in source and rasterised at load time.

### Characters, ships, worlds

`src/lego/minifig.js` is the minifigure rig: hips, legs, torso, sloped
shoulders, cylindrical arms, C-shaped hands, a head that turns, and
`pose`/`walk`/`run`/`aimBlaster`/`fall` helpers so nobody stands around like a
mannequin. `src/models/` builds the cast, the fleet (corvette, Star Destroyer,
X-wing with working S-foils, TIE, Falcon, sandcrawler, escape pod) and the
worlds (procedurally textured planets, a battle station with a real modelled
trench, ship interiors, dune fields that answer `heightAt(x, z)`).

LEGO explosions throw actual bricks.

### Sound

`src/audio/` synthesises the entire soundtrack with the Web Audio API: an
original orchestral score with two recurring motifs developed differently in
each scene, and around thirty sound effects from laser fire to Vader's
breathing. Nothing is sampled. Everything is scheduled ahead of time against
absolute timestamps, which is what makes an offline render possible.

The narrator is synthesised locally by [Piper](https://github.com/OHF-Voice/piper1-gpl)
(`npm run tts`), then run through a per-character ffmpeg chain: a warm
storyteller for the narration, a pitched-down cavernous chain for Vader, and a
band-limited clipped chain for squadron radio.

## Rendering the film

The whole production is deterministic. Every scene's `update(t)` is a **pure
function of time** — no accumulated velocity, no one-shot flags, no
`Math.random()` — so frames can be rendered in any order, in parallel, across
several headless browsers, and come out identical.

```bash
npm run build
npx vite preview --port 5175 &

node tools/render-audio.mjs  --out render/soundtrack.wav      # one offline pass per scene
node tools/render-frames.mjs --out render/frames --fps 24 --w 1280 --h 720 --workers 3
node tools/make-movie.mjs    --out render/lego-star-wars.mp4  # mux
```

`tools/render-frames.mjs` puts the page into `?render=1` mode, where it hands
its clock over and exposes `__seek(frame)`. `tools/render-audio.mjs` schedules
the identical soundtrack into an `OfflineAudioContext`, one slice per scene,
and mixes the slices back onto a single timeline.

## Looking at your own work

The hard part of generating a film without being able to watch one is knowing
whether it is any good. Two tools exist for that:

```bash
# a labelled grid of stills across the whole film, or one scene
node tools/contact-sheet.mjs --every 5 --out /tmp/sheet.png
node tools/contact-sheet.mjs --scene trench --n 16 --out /tmp/trench.png

# any single model on a turntable, with its bounding box and triangle count
node tools/shot.mjs "http://127.0.0.1:5173/preview.html?m=/src/models/ships.js&f=xwing&r=0.3" /tmp/x.png
```

A contact sheet catches an empty frame, a camera inside a wall, or a character
standing in the floor far faster than scrubbing a timeline would.

## Layout

```
src/lego/        brick kit, SVG textures, the minifigure rig
src/models/      characters, ships, environments
src/scenes/      one file per scene + the shared effects toolkit
src/audio/       bus, score, sound effects
src/engine/      renderer, post chain, camera shot lists
src/story.js     the screenplay: scene order, running times, narration
src/director.js  clock, cuts, subtitles, soundtrack scheduling
tools/           tts, screenshots, contact sheets, frame/audio render, mux
docs/            modelling and scene-authoring conventions
```
