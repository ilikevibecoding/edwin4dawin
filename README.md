# Hearth & Havoc

An original, responsive village-building strategy parody that runs entirely in the browser. Build and upgrade a hand-drawn isometric village, collect resources, complete quests, and command a short tactical sky voyage.

## Run locally

```bash
npm start
```

Then open [http://localhost:4173](http://localhost:4173).

No package installation or build step is required. Progress is stored in the browser with `localStorage`.

## Controls

- Drag the village to pan and use the mouse wheel to zoom.
- Select a building to collect resources or start an upgrade.
- Open **Build** to place economy, army, and defense buildings.
- Open **Voyage** to choose a crew and attack rival targets.
- Double-click a resource building for quick collection.

## Development checks

```bash
npm test
npm run check
```

The project uses only browser APIs and Node's built-in test runner.
